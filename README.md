
# TAMBAYAN
Solar-Powered Charging Station Integrated with
RFID-Based Payment and Management System

Project Overview
TAMBAYAN is a solar-powered charging station
with RFID-based access, cashless payments,
charging session management, and monitoring.

Web Portals
- Super Admin Dashboard
- Authorized Reloader Terminal

Technologies
- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Firebase Realtime Database
- GitHub for version control

Project Files
- index.html — Super Admin interface
- reloader.html — Authorized Reloader interface
- script.js — Admin application logic
- style.css — Admin interface styling

Project Status
Prototype / Development and Testing

Financial operations require additional
server-side safeguards before production use.
